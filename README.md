# Ev3 – App IoT de pulsaciones (Android)

> **Proyecto académico** (Evaluación 3, Aplicaciones Móviles IoT, dic-2024).

App Android en Kotlin con autenticación (login, registro, cambio de contraseña) y registro/visualización de pulsaciones cardíacas con Firebase.

## Stack
Kotlin, Android Views/Fragments, Firebase Authentication y Realtime Database.

## Configuración
1. Crea un proyecto en [Firebase Console](https://console.firebase.google.com/) y agrega una app Android con el paquete `com.example.evaluacion3`.
2. Descarga `google-services.json` y colócalo en `app/` (el repo solo incluye `app/google-services.json.example`).
3. Habilita Authentication (correo/contraseña) y Realtime Database.
4. Abre en Android Studio y ejecuta.

> No verificado en CI: el proyecto no se compiló en el entorno de preparación.
